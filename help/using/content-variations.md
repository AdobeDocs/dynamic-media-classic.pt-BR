# Gerenciar variações de conteúdo{#managing-content-variations}

Use conjuntos de modelos para gerenciar a forma como as variações de ativos são publicadas.

Crie um conjunto de modelos para gerenciar variações de um modelo. Você pode controlar qual variação é usada sem alterar o código no site. Esse método permite que os gerentes de conteúdo atualizem o conteúdo sem precisar de suporte técnico para alterar um URL no código da Web.

URLs universais exibem a variação do modelo na página, com base na ordem definida. O modelo na parte superior da lista de conjuntos de modelos é sempre publicado.

Você pode usar qualquer URL de predefinição de imagem da lista. Os URLs de predefinição de imagem funcionam de forma semelhante aos URLs universais. Pode haver mais de um URL de predefinição de imagem.

**Para gerenciar variações de conteúdo:**

1. Vá para **[!UICONTROL Build]** > **[!UICONTROL Template Sets]**.
1. No construtor, selecione um modelo e, em seguida, **[!UICONTROL Add/Preview]**.
1. Modifique as propriedades do modelo e selecione **[!UICONTROL Save As]** para criar outra versão.
1. Digite um nome e selecione **[!UICONTROL Save]**.

   O ativo e o modelo devem ser publicados.

1. Vá para a página Detalhes para obter uma cópia do URL da seção URLs.

É possível reordenar um modelo (por exemplo, para a primeira posição na lista) arrastando-o para o novo local. Publique novamente para enviar o novo pedido.

>[!NOTE]
>
>Se necessário, limpe o cache para ver as alterações. A alteração só é exibida no site depois que a alteração é processada por meio do ciclo de cache.
